## Kullanım

Katalogdan ihtiyacınıza uygun skill'i açın. `SKILL.md` dosyasını ve başvurduğu destek dosyalarını kullandığınız AI aracına bağlam olarak verin. Taşıma veya kurulum sırasında yalnızca `SKILL.md` dosyasını almak yerine skill klasörünü ve ilgili ortak referansları birlikte koruyun.

Her kaynak kendi kurulum ve çalışma yaklaşımını anlatır; kaynak README dosyalarına bakın. Derlemenin kökü ortak bir otomatik skill yükleyicisi değildir. Bu çalışma sırasında kaynak script'ler çalıştırılmadı ve araçlar arasında kurulum uyumluluğu test edilmedi.
